Methods for querying and retrieving documents.

## get()

Get a document by ID.

### Signature

```ts
get(id: string): DocumentEmbedding<T> | undefined
```

### Return Value

Returns the full document embedding or `undefined` if not found.

```ts
interface DocumentEmbedding<T> {
  id: string;
  vector: Float32Array;
  metadata: T;
  text: string;
  createdAt: Date;
}
```

### Example

```ts
const doc = db.get('users:list');

if (doc) {
  console.log(doc.metadata.toolName);
  console.log(doc.text);
  console.log(doc.createdAt);
}
```

## filter()

Get documents matching a filter (without semantic ranking).

### Signature

```ts
filter(filterFn: (metadata: T) => boolean): DocumentEmbedding<T>[]
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `filterFn` | `(metadata: T) => boolean` | Filter predicate |

### Return Value

Returns all matching documents in insertion order (not ranked by similarity).

### Example

```ts
// Get all billing tools
const billingTools = db.filter((m) => m.owner === 'billing');

// Get deprecated tools
const deprecated = db.filter((m) => m.deprecated === true);

// Combine conditions
const results = db.filter(
  (m) => m.owner === 'users' && !m.deprecated
);
```

<Note>
Use `search()` with a filter for semantic ranking. Use `filter()` when you only need metadata-based retrieval without similarity scoring.
</Note>

## getAll()

Get all documents.

### Signature

```ts
getAll(): DocumentEmbedding<T>[]
```

### Example

```ts
const allDocs = db.getAll();
console.log(`Total: ${allDocs.length} documents`);
```

```ts
keys(): string[]
```

---

## values()

Get all document embeddings.

### Signature

```ts
values(): DocumentEmbedding<T>[]
```

### Example

```ts
const docs = db.values();
for (const doc of docs) {
  console.log(doc.id, doc.metadata);
}
```

## getStats()

Get database statistics.

### Signature

```ts
getStats(): VectoriaStats
```

### Return Value

```ts
interface VectoriaStats {
  totalEmbeddings: number;
  dimensions: number;
  estimatedMemoryBytes: number;
  modelName: string;
}
```

### Example

```ts
const stats = db.getStats();

console.log({
  documents: stats.totalEmbeddings,
  dimensions: stats.dimensions,
  memoryMB: (stats.estimatedMemoryBytes / 1024 / 1024).toFixed(2),
  model: stats.modelName,
});
```
